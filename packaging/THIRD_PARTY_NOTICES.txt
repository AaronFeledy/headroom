Headroom third-party notices
============================

Each packaged build includes its collected runtime and source-attribution
license material under share/licenses. The package manifest hashes those files
along with the executable payload.

Qt 6.12.0
---------
Headroom uses Qt Core, GUI, Widgets, Network, QML, Quick, Quick Controls 2 and
SVG, plus Qt platform, image, icon and TLS plugins. Qt is available under its
applicable commercial and open-source licenses. See share/licenses/qt and
https://www.qt.io/licensing/ for the corresponding terms and source offer.
share/licenses/qt/attributions/index.json identifies the exact verified Qt
source archives used for the notice inventory, preserves each module's
qt_attribution.json records and referenced files, and states whether the build
kit supplied additional SPDX SBOM files. This conservative module-source
inventory includes build and example provenance where Qt does not provide an
exact binary SBOM; the index labels those records rather than claiming they are
all linked into Headroom.

.NET 8 credential helper (Windows packages)
-------------------------------------------
The self-contained Windows credential helper includes the .NET runtime,
Microsoft.Data.Sqlite, SQLitePCLRaw and the SourceGear.sqlite3 native SQLite
distribution. The package preserves the resolved NuGet names and versions,
nuspec metadata, shipped license/notice files, and applicable MIT or Apache 2.0
license text under share/licenses/nuget.

Go runtime and server dependencies
----------------------------------
The stable launcher, package validator and usage-server include the Go runtime.
The Go runtime license and the exact protobuf v1.36.11 and YAML v3.0.1 license
and notice files are included under share/licenses/go. The CLI and manager also
include golang.org/x/sys and golang.org/x/term for native process identity and
terminal handling; their BSD licenses are preserved under share/licenses/go.

Microsoft Visual C++ runtime (Windows packages)
-----------------------------------------------
The app-local MSVC runtime files are redistributed under Microsoft's Visual
Studio licensing terms. See share/licenses/msvc.

OpenSSL (Linux packages)
------------------------
Headroom's Qt TLS backend uses the OpenSSL 3 runtime supplied by the documented
Ubuntu 22.04-compatible desktop baseline. The official package recipe excludes
that system library from the bundle and includes the baseline distribution's
OpenSSL copyright and license inventory under share/licenses/openssl.
