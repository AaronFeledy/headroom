# Security policy

Security fixes ship in the next Headroom release; only the latest release is
supported. Update with `headroom update` or by rerunning the installer.

## Reporting a vulnerability

Please don't report vulnerabilities in public issues or pull requests. Report
them privately through GitHub instead: on the repository's **Security** tab,
choose **Report a vulnerability**, or go straight to
https://github.com/AaronFeledy/headroom/security/advisories/new.

Include the Headroom version, your OS, and steps to reproduce. Never include
tokens, provider credentials, browser cookies, or live account output; a report
doesn't need them.

Follow-up happens in the private advisory. Once a fix is released, the advisory
is published with credit to you, unless you'd rather not be named.
