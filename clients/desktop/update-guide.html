Update Headroom

This guide is installed for source and system-managed builds. Official per-user packages check once after normal startup, automatically download and verify a newer native package, and offer Restart to apply only after a complete stage is ready.

Source installation

Use the checkout that contains clients/desktop. Review incoming changes and preserve any local work before changing the checkout. Headroom does not update a source checkout or run code fetched by this guide.

Run these commands from the repository root:

cmake -S clients/desktop -B clients/desktop/build -DCMAKE_BUILD_TYPE=Release
cmake --build clients/desktop/build --parallel
ctest --test-dir clients/desktop/build --output-on-failure

On Windows, use the same CMake source with an architecture-matching Qt kit and Visual Studio developer shell. See the Windows source instructions for the native configure and test commands.

On Linux, after the build and tests succeed, choose Quit Headroom, install with the same prefix used previously, and reopen it:

cmake --install clients/desktop/build --prefix "$HOME/.local"
"$HOME/.local/bin/headroom"

The install changes application files only. Connection settings, provider order, and any saved bearer token remain in the current-user settings file.

System-managed installation

Use the update command and repository configured by your operating system or package administrator, then quit and reopen Headroom. A system-managed build does not download public Headroom release assets or write into the per-user package root.

External per-user reinstall

If you rerun an official installer while Headroom is already open, quit and reopen the app after installation. The verified files are replaced on disk, but a launcher invocation may activate the existing primary process until it exits.

Source requirements

CMake 3.25+, a C++17 compiler, and Qt 6.12+ with Quick, Quick Controls 2, Widgets, Network, SVG, and Test. Linux package builds also use Qt WaylandClient. Tests bind isolated loopback fixtures and render Qt offscreen.
